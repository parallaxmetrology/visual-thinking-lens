# Overclaim patterns

| pattern | example | safer frame |
|---|---|---|
| **metric to quality** | "higher SDI, so the composition is stronger" | "mass is more dispersed under this measure" |
| **one image to prior** | "this image shows Midjourney's center bias" | "this image is centered; a prior claim needs a comparable set" |
| **comparison without matching** | "Engine A is more centered than Engine B" (different resolutions, versions or machines) | "within this matched subset…" or "provisional: settings differ in…" |
| **QA as footnote** | FAIL rows averaged in, mentioned at the end | "excluding n invalid rows…" or block the claim |
| **channel isolation** | "low μ proves fragmentation of meaning" | "μ is low (component structure); with SDI and xₚ this reads as…" |
| **centered = collapse** | "every centered image is a default" | "centered by one body" vs "centered by balance"; a default needs low variance across varied prompts |
| **void = r_v** | "r_v 0.9 means 90% empty space" | "90% of the frame is below the absolute gradient threshold" |
| **prompt obedience** | "the model followed the composition instruction" | "measured structure moved in the intended direction (Δx +0.08 across n pairs)" |
| **causal language** | "the off-center placement causes tension in viewers" | "is associated with…" or "would need a viewer study" |
| **cross-instrument blending** | VTL Δx compared directly with RCA-2 dx, or with ISR values | name each instrument; they use different masks and resolutions |
| **object ≠ reproduction** | "Vermeer placed the mass at…" from a museum JPEG | "in this reproduction (source, crop, resolution)…" |
| **precision theater** | "Δx = 0.04217 shows a slight right bias" (single image, cross-platform) | round to what's stable (~0.001 across machines); single image is local |
| **hidden selection** | "AI images are more centered" from a hand-picked set | state how images were chosen and how many |
